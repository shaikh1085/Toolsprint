4Copy or download

Frequently asked questions

My objects have different keys. What happens?

The header row is the union of all keys across all objects, in the order they first appear. Objects missing a key simply get an empty cell in that column — no column is ever dropped.

How are nested objects and arrays handled?

They are stringified into compact JSON inside the cell (and quoted, since JSON contains commas). Flat scalar values — strings, numbers, booleans — go in as they are; null becomes an empty cell.

Why are some values wrapped in quotes?

That is the CSV standard: any value containing a comma, a double quote or a newline must be wrapped in double quotes, with each inner quote doubled. Spreadsheets rely on this to keep columns aligned.

What if my JSON is a single object, not an array?

It is treated as a one-row CSV. If your JSON is neither an object nor an array of objects, the tool shows an error explaining what it needs instead of producing garbage.

Frequently asked questions

How do the category filters on this page work?

Tap a category pill — Image, PDF, Text, Developer, Generator, Calculator or Timer — and the list narrows to that group only. The filters combine with the search box, and the line above the grid always shows how many of the 51 tools are currently visible.

What is the difference between this page and the homepage?

The homepage is the highlights view: Popular tools first, then tools grouped by category, plus the “Why ToolSprint” section. This page is the flat, complete list — all 51 tools in one searchable grid, with no grouping, so nothing is more than a search away.

Why does the count say “Showing X of 51 tools”?

Because a search or a category filter is narrowing the list. “Showing 9 of 51 tools”, for example, means 9 tools match right now. Clear the search box and set the filter back to “All” to see the full 51 again.

A tool I expected is missing from this list — why?

Some tools are deliberately not offered. There are no finance or tax calculators (those are on PayWise), no colour tools (those are on Chromora), and no PDF-to-Word or video converter, because those cannot be done well entirely in your browser.

Frequently asked questions

How random are these passwords, really?

They are built with the Web Crypto API (crypto.getRandomValues), the same secure randomness your browser uses for encryption — not the predictable Math.random.

Does ToolSprintHub save or see my password?

No. The password is generated and shown only in this tab, on your device. If you close or reset the page without copying it, it is gone for good.

What length should I use?

16+ characters with all character types resists brute-force guessing extremely well. Some older sites cap passwords at 12–14 characters — match the site's limit, but never reuse that password elsewhere.

A site rejects symbols. What should I do?

Untick Symbols and raise the length to 20+. Letters and numbers at that length are still very strong.

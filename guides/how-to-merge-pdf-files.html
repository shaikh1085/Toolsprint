How to merge PDF files

Merging means taking two or more separate PDFs — say a signed contract, an ID scan and an application form — and joining them into a single file, in the order you choose. It is the fix for “please send everything as ONE attachment” emails, job applications that accept a single upload, and keeping a project's paperwork together.

Step by step

1. Open the PDF Merge tool. It runs entirely in your browser, so the files are never uploaded to a server.

2. Add your PDFs. Pick two or more files. Each one appears in a list showing its name and how many pages it has — check the page counts to be sure you picked the right documents.

3. Put them in order. Use the up/down buttons on each file, or drag files into place. The merged document reads top to bottom in list order, so put the cover page or main document first.

4. Merge and download. Press Merge, then Download. Open the result and flip through it before you send it anywhere.

Tips that save you a re-do

Check the order before merging, not after. The page counts in the list are your friend: if a 1-page form suddenly shows 12 pages, you picked the wrong file.

Name the output clearly. Rename the downloaded file to something the receiver understands — Smith-application-complete.pdf beats merged.pdf.

Big scans stay big. Merging adds the files together; it does not shrink them. If the result is too large to email, run it through the PDF Compressor afterwards — Basic mode first.

Keep your originals. Merging never changes the source files, but keep them anyway until the receiver confirms the merged copy is fine.

Common mistakes

Merging password-protected PDFs. An encrypted file cannot be merged until the password protection is removed by its owner. The tool will tell you the merge failed rather than producing a broken file.

Assuming pages rotate automatically. They don't — a sideways scan stays sideways. Fix it first with the PDF Rotate tool.

Frequently asked questions

Is there a limit to how many PDFs I can merge at once?

There is no fixed number limit, but very large totals (hundreds of pages or tens of megabytes) depend on your device's memory. If a huge merge struggles, merge in two groups and then merge the two results.

Will merging reduce the quality of my PDFs?

No. The pages are copied into the new file exactly as they are — text stays selectable, images keep their resolution. Quality only changes if you later compress with Strong mode, which is a separate, clearly labelled step.

Can I merge just some pages from each file?

Not in one step. First use PDF Split to extract the page range you want from each file, then merge those extracts.

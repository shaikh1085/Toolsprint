How to split a PDF

Splitting is the opposite of merging: you have one large PDF — a 200-page report, a full e-book, a scanned bundle — and you only need part of it. Instead of sending the whole file, you extract a page range into a new, smaller PDF.

Step by step

1. Open the PDF Split tool. It works in your browser; the file is never uploaded.

2. Choose your PDF. The tool reads it and shows the total page count, so you know the range you can pick from.

3. Enter the page range. Type the first and last page you want — for example pages 5 to 9. For a single page, use the same number twice (7 to 7).

4. Split and download. Download the new PDF and open it to confirm it starts and ends exactly where you expected.

Tips that save you a re-do

Find the real page number first. The page number printed on the page (often in the footer) is not always the PDF page number — covers and title pages shift everything. Scroll the original PDF and count from the first page.

Extract in several passes for separate chunks. Need pages 3–5 and 20–22 as two files? Run the tool twice. Need them in one file? Extract both, then join them with PDF Merge.

Splitting is also a size fix. If a PDF is too big to email, sending the 10 relevant pages instead of all 200 usually solves the problem without any compression at all.

Common mistakes

Off-by-one ranges. Ranges are inclusive: 5 to 9 gives you five pages (5, 6, 7, 8, 9), not four. Check the first and last page of the output before sending.

Trying to split a protected file. Password-protected PDFs cannot be split until the owner removes the protection; the tool reports the failure instead of guessing.

Frequently asked questions

Does splitting change the pages themselves?

No. The extracted pages are copied exactly — text, images and layout are untouched. Only the pages outside your range are left behind, and your original file is never modified.

Can I extract pages that are not next to each other?

The tool takes one continuous range. For scattered pages, extract each range separately, then combine the pieces with PDF Merge in the order you want.

Why is my split file barely smaller than the original?

Shared resources — fonts and images used across the whole document — are copied into the extract too. For a small range from a huge file the saving is still usually large; for a range covering most of the document, it won't be.

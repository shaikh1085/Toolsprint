Frequently asked questions

Will compressing ruin my photo's quality?

At 70–85% quality most photos look identical on screen while losing half or more of their file size. Use the preview to judge before downloading — very low settings (under 40%) will show visible softness.

Why did my PNG get bigger or barely shrink?

PNG is already lossless, so re-saving it rarely helps much. The compressor outputs JPG for photos, which is where the big savings are. If the new file is bigger than the original, the tool warns you instead of letting you download a worse file by accident.

Is there a file size limit?

No server limit exists because nothing is uploaded. Very large photos (for example 100 MP camera files) depend on your device's memory — if one fails, resize it first with the Image Resizer.

Does the compressed image keep its dimensions?

Yes. Compression changes the file size, not the width and height. To change dimensions as well, run the result through the Image Resizer.

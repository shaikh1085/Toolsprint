Frequently asked questions

Does formatting change the XML's meaning?

No. Only whitespace between elements is added. Element order, attributes, text content and namespaces are preserved exactly as parsed — the output is serialised from the validated document, not edited as raw text.

Why did my HTML not format?

HTML is usually not valid XML — unclosed tags like <br> or <img> are legal HTML but broken XML, and the parser error will name the first offending spot. This tool is for real XML: feeds, configs, SVG and sitemaps.

What indentation does it use?

Two spaces per level, with text-only elements kept on one line so values stay easy to scan and diff.

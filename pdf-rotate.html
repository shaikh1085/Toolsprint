PDF Rotate

Fix PDFs that open sideways or upside down. Every page is rotated by the angle you choose, and the rotation is saved into the file itself.

Choose one PDF file.

Private: Your file is processed in your browser and never uploaded.

How to use

1Choose a PDF
The sideways or upside-down one.
2Pick the angle
90° if pages face left, 270° if they face right, 180° if upside down.
3Rotate
Existing page rotation is respected and added to.
4Download
The saved file opens the right way up everywhere.

Frequently asked questions

Can I rotate only some pages?

Not with this tool — it rotates every page, which is what scanned documents usually need. To fix a single page, split it out with PDF Split, rotate it, and merge it back.

I rotated the wrong way. Can I undo it?

Yes — run the tool again on the rotated file with the opposite angle (90° the other way is 270°). Your original file is never modified, so it is also safe to start again from that.

Does rotating reduce quality?

No. Only the page rotation flag changes — the content, text and images are untouched, so the file stays the same size and quality.

Privacy Policy

Last updated: 5 November 2026.

Your files

Files you open in a ToolSprint tool are processed in your browser and never uploaded. Merging, splitting, compressing, converting and generating all happen on your own device. ToolSprint has no copy of your files, cannot see them, and cannot recover them for you if you close the tab.

Your text

Text you type or paste into a tool (for the word counter, formatters, generators and similar tools) is handled the same way: it stays in the page, on your device. Generated results — passwords, hashes, UUIDs — are created locally and are not stored or sent anywhere by ToolSprint.

Accounts and tracking

ToolSprint has no accounts and no sign-up, so it collects no names, email addresses or passwords. This version of the site sets no tracking cookies and runs no analytics scripts.

Advertising

Tool pages contain an empty advertising placeholder. If advertising is enabled in future, this policy will be updated first to name the network and the cookies it uses, before any ad code is added.

Third-party libraries

Some tools load well-known open-source JavaScript libraries (for example a PDF library or a QR library) from a content delivery network. Your files and text are never sent to those networks — only the library code itself is downloaded, the same way a font or image would be.

Questions

If anything on this page is unclear, ask via the Contact page.

Frequently asked questions

If I close the tab, can ToolSprint recover my file or text for me?

No — and that is the proof of how this works. ToolSprint never received your file or text in the first place, so there is no copy on a server to recover. Keep your own copy of anything important before you close the page.

Are the passwords and hashes I generate stored anywhere?

No. Passwords, hashes, UUIDs and other results are created locally in your browser tab. They are not stored, logged or sent anywhere by ToolSprint — save a generated password in your own password manager straight away.

Does ToolSprint set tracking cookies or run analytics?

Not in this version of the site. There are no accounts, so no names, email addresses or passwords are collected, and this version sets no tracking cookies and runs no analytics scripts.

If adverts are added later, will this policy change first?

Yes. Tool pages currently show only an empty advertising placeholder. If advertising is ever enabled, this policy will be updated first to name the network and the cookies it uses, before any ad code is added to the site.

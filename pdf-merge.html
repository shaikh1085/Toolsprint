PDF Merge

Combine two or more PDFs into one file, in exactly the order you want. Reorder with the ↑ ↓ buttons or by dragging, remove any file, and check each file's page count before you merge.

Drag & drop PDF files here, or choose them — you can add more at any time.

Private: Your file is processed in your browser and never uploaded.

How to use

1Add your PDFs
Pick two or more files. Each one shows its name, size and page count.
2Arrange the order
Use ↑ and ↓, or drag a row to where it belongs. The merged file follows this order.
3Merge
Press Merge PDFs and wait for the total page count.
4Download
Save the combined PDF to your device.

Frequently asked questions

Is there a limit to how many PDFs I can merge?

There is no set number — the limit is your device's memory. Dozens of normal documents merge fine; hundreds of scanned pages may be slow on a phone.

Will the merged PDF keep bookmarks and links?

Pages, text, images and internal links are copied across. Outlines/bookmarks from the source files are not carried over by the in-browser library, so check navigation after merging if that matters to you.

One of my PDFs is password-protected. What happens?

Protected files cannot be read, so the tool will name the file and stop with a clear error instead of producing a broken merge. Remove the password in your PDF app first, then merge.

Does merging reduce the file size?

Not reliably — the merged file is roughly the sum of its parts. If size matters, run the result through the PDF Compressor afterwards.

Frequently asked questions

Does it handle daylight saving time?

Yes. The conversion uses the full IANA time-zone database built into your browser, so a July date and a January date between the same cities can correctly show different offsets.

Why did the result land on a different day?

Big offsets cross midnight: 9am Monday in Sydney can be Sunday evening in New York. The result always shows the full date so the day shift is obvious, never hidden.

How is the “from” time interpreted if I type it?

As wall-clock time in the from-city: “15:00 in Karachi” means 3pm as a clock in Karachi reads, and the tool finds that same instant in the other city.

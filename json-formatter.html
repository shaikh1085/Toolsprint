How to use

  

    
1Paste your JSON
From an API response, a config file or anywhere else.

    
2Format or minify
Format adds indentation for reading; Minify strips it for size.

    
3Fix any errors
Invalid JSON produces a specific error message, not a silent failure.

    
4Copy the result
One click copies the output, with “Copied!” confirmation.

  


  
Frequently asked questions

  

    
What makes JSON “invalid”?
The usual culprits: trailing commas, single quotes instead of double quotes, unquoted keys, or comments. The error message names the problem the parser hit — fix that spot and format again.

    
Does formatting change my data?
No. Format and Minify only change whitespace. Keys, values, order and types come out exactly as they went in — the tool re-serialises the parsed value rather than editing your text.

    
Is my JSON uploaded for validation?
No. Parsing uses your browser's built-in JSON parser, on your device. API keys or tokens inside your JSON never leave the tab.

    
Can it format a JSON array, not just an object?
Yes — any valid JSON value works: objects, arrays, and even a bare string, number or boolean, though objects and arrays are what most people paste.

Frequently asked questions

Which sizes do I actually need?

Minimum for a normal website: 16 and 32 (browser tabs), 180 (Apple devices) and 192 + 512 (Android/PWA install icons). This tool makes all of them plus 48, so you are covered in one download.

Why does my favicon look blurry or unreadable at 16 px?

Detailed logos and text do not survive 16 px. Use a simplified mark — one letter or one bold shape — for the small sizes; the preview row shows exactly how each size will look.

Is the ZIP a real ZIP file?

Yes — it is assembled in your browser using the ZIP stored format, and every operating system and host can open it. No library or server is involved.

What link tags should I add?

At minimum: a PNG icon link for 32×32, an apple-touch-icon link for 180×180, and 192/512 entries in your web app manifest if you have one.

PDF Compressor — Basic compression

Two honest modes. Basic re-saves the PDF with optimised structure and keeps text selectable. Strong re-renders each page as an image, which can shrink scanned PDFs a lot.

Please read before you compress: already optimised PDFs may not shrink at all — many PDFs from modern apps are already as small as Basic mode can make them. The Strong option converts pages to images, so text becomes non-selectable and cannot be copied or searched. Use Strong mainly for scanned documents.

Frequently asked questions

Why didn't my PDF shrink in Basic mode?

Because it was probably already optimised. Basic mode removes structural waste (unused objects, uncompressed streams); a PDF exported by a modern app often has none. The tool tells you the real before/after sizes instead of pretending.

When is Strong mode worth it?

For scanned PDFs: a scan stores a huge photo per page, and re-rendering it at screen resolution can cut the file dramatically. The price is real — pages become pictures, so no text selection, no search, no copy-paste.

Can Strong mode make the file bigger?

Yes, for text-heavy PDFs with small original images. If the result is bigger, the tool warns you and you should keep the Basic output (or your original) instead.

Is the compressed PDF lower quality in Basic mode?

No. Basic mode does not touch images or text — it only re-packs the file structure. Quality loss is only possible in Strong mode, from re-rendering.

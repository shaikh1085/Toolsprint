Frequently asked questions

Can I crop more from one side than another?

Not in this tool — it trims evenly from all four sides, which is what you want for removing borders and letterboxing. For uneven crops, use a photo editor.

What is the maximum crop?

45% per side. Beyond that almost nothing of the image would remain, so the tool stops there and says so.

Does cropping change the file size a lot?

Fewer pixels usually means a smaller file, and the size line shows original → new with the percent saved. PNG output can occasionally be larger; the tool warns you when that happens.
